# DevArena

Coding leaderboard. Connect GitHub, see who's building.

## Stack

Next.js 14 · TypeScript · Tailwind · Supabase · NextAuth

## Getting started

```bash
cp .env.example .env.local   # fill in your keys
npm install
npm run dev
```

See `.env.example` for required environment variables.

## Database

Run Supabase migrations in order: `supabase/migrations/001` → `008`
